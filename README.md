# 🎮 Completionist List

Мой список закрытия игр: для каждой игры — свои условия закрытия и прогресс по ним.

**Сайт:** https://dstratonov1234.github.io/completionist-list/

## Как это устроено

- `data/games.json` — все игры и их статусы
- `data/conditions/` — условия закрытия каждой игры (импорт из моих `УСЛОВИЯ_ЗАКРЫТИЯ.md`)
- `index.html` + `assets/` — статический сайт на GitHub Pages, без сборки: у каждой игры своя страница с условиями закрытия и собственным UI/UX/VFX в стиле самой игры
- `themes/<игра>/` — уникальное оформление игры: стили, модуль с интерактивом и эффектами, сгенерированные ассеты
- `scripts/` — импорт условий закрытия, арт из Steam и вики, генерация ассетов, палитры и шрифты, проверка данных

Список ведёт Claude по моим сообщениям в чате — правила в [CLAUDE.md](CLAUDE.md).
