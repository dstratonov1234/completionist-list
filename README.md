# 🎮 Completionist List

Мой список игр: что уже закрыто на 100% и больше никогда не вернусь, что прохожу сейчас и во что планирую сыграть.

**Сайт:** https://dstratonov1234.github.io/completionist-list/

## Как это устроено

- `data/games.json` — все игры и их статусы
- `reports/` — отчёты о прохождении закрытых игр
- `index.html` + `assets/` — статический сайт на GitHub Pages, без сборки: у каждой игры своя страница с артом, скриншотами, боссами и ачивками, оформленная в стиле самой игры (цвета, шрифты, частицы, текстуры)
- `themes/` — дополнительные стили отдельных игр
- `scripts/` — поиск арта и достижений в Steam, картинок на вики, палитры и шрифтов для тем, проверка данных

Список ведёт Claude по моим сообщениям в чате — правила в [CLAUDE.md](CLAUDE.md).
